# Mein Portfolio

Persönliches Portfolio-Website-Projekt.

## Struktur

- `index.html` – Startseite
- `assets/css/` – Stylesheets
- `assets/js/` – Skripte
- `assets/images/projects/` – Projektbilder
- `assets/fonts/` – Schriftarten
- `pages/` – Unterseiten (z. B. Projekt-Details)
- `docs/` – Notizen und Content-Entwürfe
